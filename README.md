# 💇🏽‍♀️ Braids By Moon — Plataforma Web

Aplicação web desenvolvida com **Django**, criada para a marca **Braids By Moon**, com o objetivo de oferecer uma presença digital moderna, com sistema de blog e estrutura escalável para serviços.

🔗 **Acesse o projeto online:**
👉 https://braidsbymoon.pythonanywhere.com/

---

## 🚀 Sobre o projeto

O **Braids By Moon** é uma aplicação web desenvolvida com foco em prática profissional de backend utilizando Django, simulando um ambiente real de produção para uma marca de tranças.

A plataforma permite a publicação de conteúdos, gerenciamento de páginas e serve como base para evolução futura em um sistema completo (ex: agendamentos, catálogo de serviços, etc).

---

## ✨ Funcionalidades

* 📝 Sistema de **blog dinâmico**
* 🔐 Estrutura para autenticação de usuários
* 🧑🏽‍💻 Painel administrativo via Django Admin
* 🌐 Navegação responsiva
* 📂 Organização de posts e conteúdos
* ⚙️ Estrutura preparada para expansão (serviços, agendamentos, etc)

## ⚙️ Como rodar o projeto localmente

### 🔧 Pré-requisitos

* Python instalado
* Git instalado

### ▶️ Passos

```bash
# Clone o repositório
git clone https://github.com/CleisonF/Projeto-blog-django.git

# Acesse a pasta
cd Projeto-blog-django

# Crie ambiente virtual
python -m venv venv

# Ative o ambiente
venv\Scripts\activate

# Instale dependências
pip install -r requirements.txt

# Rode o servidor
python manage.py runserver
```
